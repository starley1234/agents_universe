MCP Servers & Tools

Model Context Protocol — расширяет агента инструментами (search, image, tts, filesystem)

Новый MCP сервер

Примеры: npx @modelcontextprotocol/server-brave-search, filesystem, github. Для stdio используйте SSE-прокси.

Как добавить MCP сервер

1. Запустите MCP сервер, например Brave Search:

npx -y @modelcontextprotocol/server-brave-search --env BRAVE_API_KEY=xxx
# или через SSE прокси:
npx @modelcontextprotocol/server-brave-search | npx mcp-remote --transport sse --port 8001

2. Добавьте URL в UI выше или в .env:

MCP_SEARCH_URL=http://localhost:8001/sse
MCP_IMAGE_GEN_URL=http://localhost:8002/sse
# Для Docker используйте host.docker.internal:
MCP_SEARCH_URL=http://host.docker.internal:8001/sse

3. Перезапустите docker compose up -d --build или нажмите Connect в UI.

Инструменты появятся в /api/mcp/servers и будут доступны агенту в Playground (автоматически выбирает нужный tool).
