# Изменения

## 0.1.0

Первый рабочий выпуск: семь продуктовых пайплайнов из `tz.txt` на
LangChain и LangGraph, интерфейс и обвязка для эксплуатации.

### Пайплайны

Каждый — граф LangGraph с общим состоянием (`task`, `trace`, `artifacts`,
`findings`, `errors`, `report`):

- `patent-clearance` — арбитраж патентной чистоты;
- `synthetic-buyer` — поиск неликвидных запчастей по описанию, а не по ID;
- `doc-restorer` — синька 70-х в скрипты Revit и AutoCAD;
- `energy-hacker` — сдвиг операций под тариф (demand response);
- `formula-reverse` — реверс рецептуры по ГХ-МС;
- `cert-validator` — досье ISO/FDA с циклом рецензирования;
- `urban-scout` — скрининг участков с учётом ЗОУИТ.

### Интерфейс

- веб-интерфейс без внешних зависимостей: каталог, редактор задачи,
  отчёты, артефакты, история, метрики;
- REST API на FastAPI со схемой на `/docs`, `/health`, `/metrics`;
- CLI: `run`, `serve`, `history`, `show`, `stats`, `purge`, `doctor`;
- журнал прогонов на SQLite: стоимость, токены, длительность, артефакты;
- очередь с пулом воркеров, таймауты, отказ при перегрузке;
- Docker, compose, systemd-юниты, `docs/OPERATIONS.md`.

### Принятые решения

- **LLM переводит, а не считает.** Деньги, геометрия, вердикты и
  сопоставления считаются кодом; модель формулирует признаки и пишет текст.
  Иначе продукт нельзя продать: экспозиция иска не может зависеть от
  настроения модели.
- **Оффлайн по умолчанию.** Провайдер `fake` — детерминированная заглушка,
  весь набор проходится и тестируется без ключей и без сети.
- **Без токена — только localhost.** Сервис отказывается стартовать на
  внешнем адресе без `ACONSTRUCTOR_API_TOKEN`.

### Исправлено

Три ошибки, найденные при написании тестов:

- `task.get(key) or demo()` подменял пустой вход клиента демо-данными —
  клиент получил бы отчёт про вымышленные объекты и счёт за него. Теперь
  подстановка только при отсутствии ключа (`core.task_input`).
- `price_of` брал первый совпавший префикс: `gpt-4o-mini` считался по цене
  `gpt-4o`, счёт завышался в 16 раз. Теперь по самому длинному префиксу.
- `secrets.compare_digest` падал на не-ASCII токене. Такой токен нельзя
  передать в HTTP-заголовке (latin-1), поэтому отказ на старте.
- Годовая экономия в `energy-hacker` считалась как «экономия за сутки ×
  250», хотя плата за мощность выставляется помесячно — эффект завышался
  в 13 раз.

### Известные ограничения

- Данные демонстрационные: номера патентов, компании, кадастровые номера
  вымышлены. Реальные коннекторы (USPTO, Росреестр, рынок РСВ) — точка
  расширения в `data/`.
- `doc-restorer` работает по уже векторизованному слою; распознавание
  растровой синьки — отдельная CV-задача перед графом.
- Одна реплика: SQLite и пул потоков. Для нескольких реплик потребуется
  вынести журнал в PostgreSQL, а очередь — в Redis.
- Docker-образ и веб-интерфейс в браузере не проверялись в песочнице
  (нет docker и браузера); логика интерфейса протестирована в node.
