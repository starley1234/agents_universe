Поставить задание и закрыть вкладку
Работает фоновый исполнитель на сервере. Задание переживёт закрытие браузера, выход из SSH и перезагрузку сервера. Не успеет за один подход — продолжит сам, пока не доделает. Оркестратор по ходу решает, какого агента подключить: сменит исполнителя, добавит шаг, назначит проверку.
